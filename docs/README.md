# Docs

- [recovery.md](recovery.md): bringing back a cart that starts in EZ-Flash's
  safe mode, and carts whose loader says `Bad NOR ID`.
- [torii-code.md](torii-code.md): the reference for Torii code, Torii's own
  cheat format.
- [research/omega-de-hardware.md](research/omega-de-hardware.md): how the
  Omega DE works: registers, memory map, launches, saves and the boot loader.
- [media/](media): the README's pictures, recorded by `just media`.

`design/` and `research/` are development notes, kept as a record of why
things are the way they are. They were written as each version was built, so
older ones describe the menu as it was then. The code and `CHANGELOG.md` say
what's true now.
