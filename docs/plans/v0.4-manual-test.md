# v0.4 manual test on the cart

The first cart test of v0.4 and v0.4.1. Everything here passed in the emulator (`just check --full`, all 196 games). The emulator can't judge feel, motion, timing on real hardware or the screen's colours, so that is what this test is for. [v0.4-review.md](v0.4-review.md) lists the decisions to judge as you go.

## Before you start

The card (`/Volumes/EZ-FLASH`) was prepared by the conductor:

- `ezkernelnew.bin` is the v0.4 build (it still says v0.3.0 in About: the version is set at release).
- `/torii/names.db` and `/torii/crc.txt` from `just names-update`: No-Intro names for 230 games (the rest keep their cleaned file names).
- `/torii/art/*.bin` from `just art-scrape`: 224 covers (GBA 157 of your 158 real games, GBC 29 of 36, GB 40 of 41; the 308 test files and romhacks have none).
- Untouched: your games, `/SAVER` (saves and the old `Recently play.txt`, which v0.4 migrates), `/torii/logs`, and the old `/torii/theme.txt` and `/torii/themes/` (unused now; delete them whenever you like).

Install: put the card in the cart and hold R while switching the GBA on. Then:

1. Open **Settings → System → Logging** and set it to **Debug**. Leave Settings with B (that writes it).
2. Switch off and on once, so the whole test is logged from boot.

After the test, put the card in the Mac and run:

```bash
just logs /Volumes/EZ-FLASH
```

It writes `dist/logs/torii.log`. Send me that file and your notes; a number per step (1–5) for feel is enough, plus anything that surprised you.

## 1. First boot and migration

1. Power on. The first boot builds the library index; a "Library" dialog shows if it takes over half a second.
   - Note how long it takes for your ~240 games.
2. Home should face **Recent**, with your old Recently Played games in it (migrated from `/SAVER/Recently play.txt`, which then disappears at the first launch).
3. Power off and on again: the second boot should go straight to the menu (no dialog).

Feedback: boot time both times; are the Recent games right?

## 2. The carousel

1. Turn with LEFT/RIGHT, single taps and held.
2. Turn a full lap; watch the objects' scaling, the fog, the shadows, the label sliding, the dots.
3. Check the red torii glyph top left and the clock top right.

Feedback: does it hold 60 fps on the cart (any stutter, tearing, shimmering)? Is the speed right (tap 10 frames, held glide)? Are the side objects too big (0.89 scale) or the far ones too faint in dark?

## 3. Opening and closing

1. A on GBA: the object zooms, the page card rises, the title slides in. B back.
2. Do it on every item. Try A, A quickly (it should stop on the page) and B during the zoom.

Feedback: does the zoom feel snappy or slow? Any flash, jump or tearing? Is Info's open noticeably slower (its first draw is heavy)?

## 4. Game lists

On GBA (159 games), then GB, GBC, Recent, Favourites:

1. UP/DOWN, held (glide), L/R paging, LEFT/RIGHT letter jumps (the letter card).
2. START → the game popup: Favourite on and off, Game info (LEFT/RIGHT change the save type, then B), Delete → Cancel.
3. Play a game with A; play one with Clean boot; on a GBA game with a cheat file and Cheats on, Boot with addon (the cheat screen).
4. Hold L and press A on a game (hard reset, boot logo).
5. Settings → Look → Game view → List + art, then back to GBA: covers should appear after the cursor rests.

Feedback: 14 px rows readable? Scrolling smooth on the cart? Names right (No-Intro names, ", The" moved, tags gone)? Any wrong or missing cover? How long do covers take to appear? Does the loading card's bar move smoothly during the ROM copy, and does it finish near when the game starts (the copy-speed estimate is a guess: note if the bar waits at 90 % or jumps)?

## 5. Rename

1. A game's menu → Rename: type a name (try SELECT for capitals, the àé& page, L/R to move the caret), START. The list re-sorts.
2. SD card page → a test file (e.g. `4 - Tests/Hello.gba`) → START → Rename → a new name → START. Then play it: its save should follow.

Feedback: keyboard speed and layout; anything confusing (B deletes and never cancels: Cancel is a key).

## 6. SD card page

1. Browse folders in and out (B goes up), `4 - Tests/Many files` (a big folder), a file's menu, File info.
2. Delete → Cancel only (or delete a copy of something you don't need).
3. Settings → Library → Show all files: hidden folders appear; turn it back off.

Feedback: folder open time on the cart for big folders (GBA, Many files); item counts appearing; anything hidden that shouldn't be.

## 7. NOR page

1. Open NOR: storage bar and games.
2. Write a small GBA game to NOR from the SD card page's file menu (Write to NOR), then launch it from the NOR page.
3. Optional: Delete the game you just wrote (only the latest can go). Don't Format all unless you want to wipe NOR.

Feedback: the write's loading card ("Writing to NOR", bar), the storage bar, launch from NOR.

## 8. Settings

1. Scroll the whole page; edit values in place (A, LEFT/RIGHT, A or B).
2. Theme: flip Light/Dark and watch the wipe come down. Flip back mid-wipe.
3. Time and Date (field card); 24-hour clock off and on.
4. A hotkey: select Sleep keys, A, then press a combination; try a refused one.
5. LED colour swatches (watch the cart's LED change live).
6. Leave with B: a short black pause while the settings are written once.

Feedback: does the wipe's edge look clean on the cart's screen (mGBA can't show tearing here)? Is the black pause on leaving noticeable? Any setting that didn't stick after a power cycle?

## 9. Info and Diagnostics

1. Read Controls, In game, Your cart, About. Is anything wrong or unclear?
2. Run Diagnostics from Info; B back.

## 10. In game

1. With Back to menu on, play a game and press L+R+START: back to the menu, which should open where you left it.
2. Sleep (L+R+SELECT) and wake (START+SELECT).
3. Play Pokémon Emerald (or any game with a save), save in game, reset, check the save is there.

## 11. Light and dark

Repeat a quick lap of 2–8 in the other theme. Feedback: contrast on the cart's screen (light hint labels, danger red, selected rows).

## What to send

- `dist/logs/torii.log` from `just logs /Volumes/EZ-FLASH`.
- Your notes per section: what felt slow, what looked off, anything wrong.
- Photos or a short video of anything visual (tearing, colours) help a lot.
