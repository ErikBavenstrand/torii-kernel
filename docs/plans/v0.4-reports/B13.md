## What changed

- **One page for Recent, Favourites and each console** (`source/screens/games.c`, registered in `nav.c`).
  - A card of 8 rows of 14 px. Each row has the name shown, a favourite's star, a save dot and the size. Recent and Favourites rows start with the console's 8x8 mark. Recent shows when the game was played instead of the size. The title bar shows the position ("101/176").
  - Consoles and Favourites list A-Z; Recent lists newest first.
  - The keys:
    - UP/DOWN move and L/R page.
    - LEFT/RIGHT jump to the previous or next letter, with B11's letter card (A-Z lists only).
    - A plays. Holding L while pressing A (or picking Play) starts the game with a hard reset.
    - START opens the game popup and B goes home. SELECT does nothing.
  - List with art (the Settings value): B2's placeholder box, its band in the selected game's console colour, with "Size" and "Last" (played) under it.
  - "Played ago" texts are checked every 30 frames. The rows whose text changed are refreshed, including cached ones.
- **The game popup** (B11):
  - Play: starts the game with the addons Settings turns on.
  - Favourite: toggles in place, refreshes the row's star, and writes through B5.
  - Clean boot.
  - Boot with addon: opens the cheat screen when Cheats is on and the game has a cheat file; otherwise it starts the game with the addons. It is greyed out (`UI_POP_DIM`) when every addon is off.
  - Game info.
  - Delete: B11's confirmation "Delete NAME?" / "The save stays." with Cancel preselected. Cancel goes back to the popup. Delete removes the ROM only, and the index, Recent and the favourites follow.
  - GB, GBC and NES games (and NOR: entries) offer only Play, Favourite, Game info and Delete (NOR: entries have no Delete). Rename waits for B18.
  - These choices follow the conductor's decision: A and Play start with the enabled addons, Clean boot always starts clean, Boot with addon opens the cheat screen (or starts with the addons when there's no cheat file) and is greyed out when every addon is off, and GB/GBC/NES games always start clean.
- **Game info** is a page in the list's place, with the game's console, size, folder, when it was played, its save type and how to start it with a hard reset.
  - For a GBA game on the card, LEFT/RIGHT change the save type between « ». It is written to `/SAVER/NAME.mde` as the page closes (`action_set_save_type`, as v0.3's SAVE TYPE did), and the next launch uses it.
- **The cheat screen comes back** (`source/showcht.c`, restyled): the title bar (the item's icon and the game's name, "n/m" at the right), the cheats on a card in 14 px rows, and the hints "A pick · START play · B back".
  - START starts the game with the picked cheats. B goes back to the list with none.
  - `Open_cht_file` returns `CHEATS_NONE/BACK/PLAY`.
- **The library index keeps each game's display name** after its sort key: the custom name, the names database's name (B21), or the cleaned name.
  - `LIBRARY_VERSION` is 3, so every card is indexed again once.
  - `LIB_F_CUSTOM` marks a name that isn't the cleaned one; only cleaned names are told apart by their tags.
  - New calls: `lib_display`, `library_display`, `library_key`, and `lib_position`/`library_position`, which find a record's place by binary search.
  - Two games of a console that clean to the same name show B4's distinguishing tags, worked out from their neighbours as the rows draw.
- **Recent and the favourites become records** in one pass over the index when the page opens: their file names are hashed in pReadCache (`READCACHE_GAMES`). The favourites are sorted A-Z by the names shown (a stable merge sort, `source/gamelist.c`), into PSRAM at 4.5 MB (`PSRAM_GAMES_BASE`, 16 KB).
- **UI additions:**
  - `ui_item` gains `mark`/`badge`/`dot` 8x8 icons, with the flags `UI_LIST_MARKS` and `UI_LIST_CONSOLES`. With `UI_LIST_CONSOLES`, rows draw in bank 1, which gains `UI_ROLE_INK_FAV` (the stars are Favourites pink on every page). The list config's flags become 16-bit.
  - `UI_POP_DIM`, `ui_title_icon_set`, `ui_image_bank`.
  - `letter.c` makes the two "#" runs one stop per lap.
- **Actions:**
  - `action_game_facts` gives a game's save type and cheat file.
  - `action_set_save_type`.
  - `action_delete_file` treats a file already gone as deleted, so it leaves the lists.
- **nav.c:** the start place adopts the page's clamped row, so a Last place row past the list's end doesn't count as moving.

## Deviations

- **Game info is a page, not a popup card.** A floating card over the list didn't fit block 0's VRAM next to the page (it fragmented after the popup), so Game info takes the list's place with a deeper transition and comes back to the same row.
- **List with art shows two facts (Size, Last), not three.** The 80x80 box leaves room for only two 12 px lines inside the card. The save shows as the row's dot.
- **The index format changed** (display names stored, `LIBRARY_VERSION` 3, `LIB_F_CUSTOM`). Rows read names without cleaning or reading `names.txt`.
- **Hard reset with L+A on the list:** L pages the list, so the page remembers the row L paged away from and starts that game. The popup's Play with L held needs no such trick.
- **The Favourites order lives in PSRAM at 4.5 MB** (16 KB of the old SD-theme reserve). `READCACHE_GAMES` borrows pReadCache 0x8000-0x20000 while a page opens.
- **The empty-page golden moved to Settings,** the only empty item left (SD card waits for B14).
- **Not done:** `EN_GAME_DELETE` stays a literal format, as `lang.h`'s convention keeps formats literal for the compiler's checks.

## Decisions the user may want to contest

- **What each launch does:**
  - A and Play start the game with the addons Settings turns on. Clean boot always starts it clean. Boot with addon opens the cheat screen when Cheats is on and there is a cheat file, else starts with the addons; it is greyed out when every addon is off. (The conductor decided this.)
  - GB, GBC and NES games and NOR: entries get no Clean boot or Boot with addon; NOR: entries get no Delete.
- **The hard reset:** hold L with A on the list (the game L paged away from starts), or hold L while picking Play, Clean boot or Boot with addon. Game info's last line says "Hard reset: hold L with A".
- **Look:**
  - Stars are Favourites pink on every page, not the page's accent.
  - The save dot is ink2 left of the size.
  - Console marks use the console inks.
  - The Favourites page shows no stars.
  - Recent shows nothing at the right when the time is unknown, rather than the size.
  - Sizes read "256 KB", "1.5 MB" (under 10 MB, when not whole) and "16 MB".
  - "No games here" shows when a page becomes empty, for example after deleting its last game.
- **Hints:** "A play · START menu · «» letter · B back" (Recent has no letter chip), and "«» save type · B back" in Game info.
- **Letter jumps:** the two "#" runs (digits and symbols before A, other scripts after Z) are one stop per lap, at the first run's start.
- **Favourites:**
  - Un-favouriting on the Favourites page keeps the row until the popup closes, then it leaves.
  - Favourites outside the index sort by the first 12 bytes of their cleaned name's key.
  - Opening Favourites with thousands of entries takes up to about 1.8 s (3,367 favourites, measured).
- **Recent's rows** resolve to index records, so they show custom names, sizes and save dots. A path outside the index (a NOR game, a hidden folder) shows its cleaned file name.
- **"Played ago"** is checked every half second, so a change shows up to 0.5 s late.
- **Delete of a file that is already gone** counts as deleted: it leaves Recent, the favourites and the index.
- **Game info's lines:** Console, Size, Folder, Played, Save type (GBA on the card), Hard reset. A save type change is written as the page closes.
- **The cheat screen:** START plays, and releasing B goes back with no cheats kept. Picked entries are in the item's ink with "On" at the right.
- **Two games that clean to the same name** in different folders with the same tags show the same name. The rows pass file names, not paths, to B4's dedupe.

## Bugs

- **The cheat parser drops spaces from cheat names** ("Infinitelives"). This is pre-existing in v0.3's parser.
- **Opening Favourites with thousands of entries blocks for up to about 1.8 s** (resolving and sorting 3,367 favourites). It runs between the fade out and in. A cache across visits, or a job, is a v0.4.2 item.
- **The selected row's marquee keeps scrolling under an open popup.** This is harmless and costs about 13k cycles a frame.
- **A first visit to a game page right after a failed launch** briefly shows an empty card. "No games here" is suppressed, but the rows appear only when the index reloads (a few frames).
